WoW SteamOS Installer — World of Warcraft setup for Steam Deck and Linux.

Download **WoW-SteamOS-Installer.desktop**, allow execution in Dolphin if needed, and double-click it in Desktop Mode. The complete versioned installer is embedded; no source-folder extraction is required. Python 3.10+ and native Steam are required.

Also included: a standalone `.pyz` for terminal use, the full MIT-licensed source ZIP, and SHA256SUMS for all three downloads.

Choose WoW editions, install through Battle.net, and create direct game shortcuts sharing one Proton environment. Existing setup state and game locations are retained across the rename. This release uses neutral project attribution and removes personal references from the distributed files.

This is an early testing release. Physical Steam Deck and Bazzite validation is pending. Edition availability and direct authentication depend on Blizzard's clients. Read the README before running. Do not run with sudo.
