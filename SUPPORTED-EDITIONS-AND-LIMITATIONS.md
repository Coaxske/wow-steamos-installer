# Editions and platform limits

Retail and Classic Era are the core setup choices. Forever works on Steam Deck as of C44. Forever remains experimental beyond the recorded scope. Earlier recorded checks were bounded to character selection/creation; there is no separate recorded test of client 1.60.1.70862. No new test or full-gameplay claim is added by this documentation correction. Availability depends on the player’s account, region, service and official clients. Other test/PTR/Classic products are unsupported or experimental and have no accepted core coverage.

All selected installed editions use exactly ONE installer-managed **Battle.net** Steam tile for this copy and its controller association. Choose edition/account inside ordinary Battle.net and press Play. Separate WoW/edition tiles and automatic routing are deferred. Existing third-party addon managers/addons are preserved; manager integration is unavailable.

Automatic main-launcher exit requires the backed-up Close after Play preference configured/verified in normal guided setup. It affects this installation in BOTH Desktop and Game Mode; shared changes require explicit consent. A saved preference alone does not establish runtime exit. Main Battle.net, Agent, game and windows are separate observations. Hiding, loss of focus or exit after the game ends does not satisfy launcher exit while the same game survives. Steam's Exit game stops the whole tile.

Earlier C43 actual Steam Deck Game Mode Era/Retail automatic-exit, normal-quit and same-tile results are historical evidence. Candidate 48 has not been run on Steam Deck. Its discovery, repair and public-build changes do not constitute new game or controller acceptance. Era's pointer/menu worked with the existing generic Battle.net layout. Right-trackpad Mouse/Left Mouse Click guide covers menus, not complete gameplay. Existing custom layouts remain untouched; automatic pointer configuration is unavailable.
